# AI Agent Plans Directory

This directory contains structured plans for AI agent collaboration on the Atomic Momentum project. Each subdirectory focuses on specific aspects of the iOS-first development strategy.

## Directory Structure

### `/ios-optimization/`
Plans for iOS-specific improvements, native patterns, and performance optimizations.

### `/feature-parity/`
Analysis and migration plans for bringing web application features to the Flutter iOS app.

### `/architecture/`
Code organization, refactoring, and architectural improvements for both platforms.

### `/data-sync/`
Unified data layer strategies for cross-platform data management and synchronization.

### `/performance/`
Performance optimization plans specific to iOS deployment and user experience.

## How to Use

Each plan directory contains:
- **README.md**: Overview and current status
- **plan-[number].md**: Specific implementation plans
- **context.md**: Background information and dependencies
- **progress.md**: Implementation progress tracking

## AI Agent Guidelines

When working with these plans:
1. Always read the relevant plan context before implementing
2. Update progress.md after completing tasks
3. Create new plan files when discovering additional requirements
4. Reference specific plan files in commit messages
5. Maintain consistency with established patterns
